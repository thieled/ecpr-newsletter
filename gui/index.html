ECPR Newsletter – Control Panel

0. Log in & requirements

You must be logged into GitHub and have collaborator access to the repository.

All actions are executed via GitHub Actions and fully versioned.

1. Create new issue

2. Upload images and documents

Upload files directly via the GitHub web interface:

  • issues/<year>/<issue>/img/ for images
  • issues/<year>/<issue>/doc/ for documents

Use Add file → Upload files in GitHub.

3. Crop images

Run the image crop workflow on an existing image path.

(Advanced users only – paths must already exist in the repo.)

4. Edit newsletter content (.qmd)

Edit the newsletter file directly in GitHub:

issues/<year>/<issue>/newsletter_<year>_<issue>.qmd

Click the file → ✏️ Edit → Commit changes.

5. Render and inline HTML

This step converts the newsletter to email-safe HTML and inlines all CSS. This is required before sending via Outlook, Mailchimp, etc.

6. Copy HTML

Once rendering is complete, open the generated HTML file in GitHub and copy its contents into your mailing tool.
